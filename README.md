**3. Data Exploration & Inspection**

| Function / Attribute | Description |
|---|---|
| `df.head()` | Displays the first five rows |
| `df.info()` | Shows DataFrame information |
| `df.shape` | Returns rows and columns |
| `df.describe()` | Generates statistical summaries |
| `df.sample()` | Displays a random row |
| `df.sample(6)` | Displays six random rows |
| `df.dtypes` | Shows column data types |
| `df.columns.tolist()` | Returns column names as a list |
| `df.select_dtypes()` | Selects columns based on data types |
